# Changelog

## Unreleased

- Metadata is read for the rows on screen first, then the rest of the folder in the background
- Removing colour tags no longer removes the shortlist star
- Renaming, moving or trashing a folder updates Favorites, Recent and the back/forward history

## 1.0.0

First public release.

- Dimensions, camera EXIF, video duration/fps/codec and more as sortable, customisable columns
- List and thumbnail views, Quick Look (Space), inspector with Copy Size / Copy CSS
- Shortlist star and Finder colour tags, with filtering
- Copy / paste / move / duplicate / rename / new folder / move to Trash
- Universal (Apple Silicon + Intel) build, drag-to-Applications DMG
